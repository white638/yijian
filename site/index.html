反馈与建议 ↗
现在可以下载 Windows 安装包吗？+

当前提供 v0.3.0 桌面预览版，支持 Windows 10 22H2 / Windows 11 x64。 下载入口指向 GitHub Releases；安装包未签名，系统要求与校验信息见发布说明。

查看版本说明 ↗
需要先配置 AI 才能用吗？+

不需要。首次引导可以跳过，衣柜管理、手动与规则搭配、记录、统计和备份都可使用。自动去背景也无需额外配置 AI 服务。需要识别、模型推荐或图片美化时，再连接适合的服务。

能在手机上拍照录入或自动同步吗？+

当前优先提供 Windows 本机体验。手机照片可先传到电脑再导入；当前不提供手机直连或跨设备自动同步。手机便捷录入属于后续方向，尚无发布日期。

开源意味着什么？+

衣间源码采用 MIT 许可证。你可以免费使用、查看和修改，也可以按许可证要求分发。第三方软件和图片模型适用各自许可。使用外部 AI 服务产生的费用由对应服务商结算。
