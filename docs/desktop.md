# Windows 使用说明

衣间面向一台电脑上的个人衣柜。核心功能无需账号，照片和记录保存在本机；AI 可以在首次引导中配置，也可以跳过。

## 获取应用

**v0.3.0 桌面预览版**支持 Windows 10 22H2 / Windows 11 x64。

[下载 Yijian-0.3.0-windows-x64-Setup.exe](https://github.com/white638/yijian/releases/download/v0.3.0/Yijian-0.3.0-windows-x64-Setup.exe) · [版本说明](https://github.com/white638/yijian/releases/tag/v0.3.0)

安装包包含应用运行环境和去背景组件，无需自行安装 Python、Node.js 或模型服务。运行安装程序后，从开始菜单或桌面快捷方式打开“衣间”。若电脑缺少 Microsoft WebView2，安装程序会自动从 Microsoft 下载，需要联网。

本版安装程序尚未代码签名，Windows 可能显示未知发布者或 SmartScreen 提醒。请仅从本仓库 GitHub Releases 获取文件，核对 SHA-256：

```text
588c756faa2013346be929d85031b9cabe5b0e3c89921fcd0623bd24a26db304
```

可在 PowerShell 中对下载文件运行 `Get-FileHash -Algorithm SHA256`。完整文件名和校验值均应与本页及发布说明一致。

应用默认安装到 `%LOCALAPPDATA%\Programs\Yijian`，衣柜数据单独存放在 `%LOCALAPPDATA%\Yijian\data`。更新时下载新安装包并覆盖安装；本版不提供自动升级。覆盖安装和卸载都保留衣柜数据，清理个人数据前请先导出备份。

也可按 [README](../README.md#从源码启动) 从源码启动。源码版默认数据目录为仓库内的 `.local/data`，可通过 `--data` 指定其他目录。

## 第一次使用

1. 选择自己的 AI 服务或暂时跳过。保存配置不会自动发起推理；可主动测试连接。
2. 上传服装或配饰照片，也可以手动录入、从商品链接选择图片。
3. 核对名称、类别、颜色等信息。自动识别需要已连接的视觉模型，无法确定的属性可以留空。
4. 用自由画布、类别选择或拼图创建穿搭；衣物可拖动、旋转、缩放，并调整前后顺序。
5. 安排穿着日期，实际穿过后记录一次。定期从设置导出衣柜备份。

## 哪些功能可以直接使用

| 功能                                       | 需要的条件                                                  |
| ------------------------------------------ | ----------------------------------------------------------- |
| 衣物与配饰管理、手动穿搭、规则推荐         | 安装应用即可使用                                            |
| 日历、穿着记录、洗护、旅行打包、统计、备份 | 安装应用即可使用                                            |
| 自动去背景                                 | 安装包自带本机图片组件，无需模型密钥                        |
| 商品链接导入                               | 能访问商品页面；部分网站需要登录后使用浏览器采集工具        |
| AI 识别、模型推荐、造型对话                | 自己的模型 API、已有本地视觉模型，或支持该操作的已连接助手  |
| 图片美化                                   | 单独配置的图片编辑 API，或通过 Codex Skill 使用宿主生图能力 |

衣间不提供平台 AI 额度。API 按所选服务商计费；本地模型需要自己的设备与模型运行环境；Codex / Claude Code 使用宿主可用的能力和额度。不同接入方式支持的操作见 [助手模式](assistant-mode.md) 与 [图片美化](image-beautify.md)。

## 数据、照片与备份

衣柜记录存入本机 SQLite，照片存为本机文件。只有主动使用外部 AI 或商品链接等网络功能时，相关请求才会发送到对应服务。模型密钥在本机服务端加密保存。

上传保留规范化原图与处理图。去背景失败可继续使用原图；美化结果先预览，再由你决定是否采用。规范化原图是缩放、校正并清除元数据后的图片，建议另外保存相机原片。

设置中的 ZIP 备份包含衣物、照片、穿搭、计划、穿着与洗护记录、旅行清单和普通偏好，不包含模型密钥或助手授权。本机恢复要求空衣柜，并检查图片及记录之间的引用。完整说明见 [数据与图片](data-and-images.md)。

## 手机和其他电脑

当前本机服务只绑定本机地址。同一 Wi-Fi 下的手机也不能直接访问电脑衣柜。可以先通过已有的文件传输方式把手机照片放到电脑，再导入衣间。

在另一台电脑上使用时，可通过导出和恢复备份迁移数据。当前没有跨设备自动同步。手机便捷录入和跨设备流程属于后续产品方向，尚无发布日期。

## 遇到问题

- 图片组件未准备成功：可以先用原图录入，再检查网络并准备图片组件。
- AI 无法识别图片：核对服务地址、密钥及所选模型是否支持视觉输入；手动录入仍可使用。
- 商品链接无法解析：参阅 [链接导入](link-import.md)，使用浏览器采集工具选择已打开页面中的商品图。
- 更换电脑或系统前：先导出 ZIP 备份并另存一份。

可在 [GitHub Issues](https://github.com/white638/yijian/issues) 提交问题，附上版本、操作步骤与错误提示；请勿公开密钥、助手连接码或包含私人照片的备份。

## 从源码构建安装包

开发者在 Windows x64 环境中构建。准备 Python、Node.js 和 npm 后，在仓库根目录执行：

```powershell
python -m pip install -r requirements-desktop.lock
.\scripts\prepare_desktop_tools.ps1
python scripts/build_desktop.py --iscc .local/desktop-build/tools/inno/ISCC.exe
```

构建过程会准备网页、图片资源和安装工具，需要网络。安装文件输出到 `.local/desktop-build/release`。依赖版本已锁定；构建产物没有代码签名，也不承诺不同机器生成字节完全一致的安装包。
