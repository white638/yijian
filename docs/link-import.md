# 从链接添加衣物

在“添加衣物”中选择“从链接导入”，粘贴完整商品网址或包含网址的分享文字，点击解析。衣间会显示商品名称和候选图片；选中一张后可开启去背景、自动识别，再导入衣柜并核对信息。

“粘贴”按钮需要浏览器允许读取剪贴板；也可以直接在输入框粘贴。剪贴板只在点击按钮时读取，解析只在点击解析后开始。

## 支持的内容

- 公开商品页中声明的商品名称与图片，包括 Open Graph、Twitter 图片及 [Schema.org Product](https://schema.org/Product) 结构化数据。
- JPEG、PNG、WebP 等可读取的公开图片地址。
- 带 HTTP 或 HTTPS 网址的分享文字。

预览最多保留八张可读取的候选图，同一预览选择一张导入；预览有效期十分钟。导入后的商品来源保存在衣物备注中，商品标题可修改。尺码和实际购买日期由用户填写。

公开商品页明确给出价格和币种时，预览会显示参考价及“页面售价”“起售价”或“发售价格”标签。参考价格保留来源和抓取时间，独立保存；页面缺价、币种不明确或存在多个不能确定的价格时留空。实际购买信息可点击“用作购入价”后确认保存，或自行填写。未确认采用的参考价不计入花费与穿着成本。

得物 Polo 实测页面提供 ¥399 发售价格，当前售价数字为空，因此显示为发售参考价。价格可能随款式和活动变化，不代表实际支付金额。

链接解析与去背景可以独立使用。配置视觉模型或开启 Codex 上传自动识别后，导入图片会进入相同的识别任务，自动填写可判断的衣物属性，等待核对。

## 页面读取限制

页面需要登录、验证码、专用 App 或浏览器脚本才能显示商品时，可能无法直接读取。纯淘口令中没有 HTTP(S) 网址时也无法解析。可复制实际商品网址，或使用下面的网页采集工具。

## 国内电商

2026-09-09 的公开商品样本实测如下。平台可能按商品、地区、登录状态和时间返回不同页面，表中结果不代表所有链接都能直接解析。

| 平台与页面 | 可用方式与实测结果 |
| --- | --- |
| 京东 | 两个 `item.jd.com/<数字SKU>.html` 链接自动对应到同一 SKU 的官方手机商品页，均提取到商品图；另一个手机商品页样本通过。 |
| 淘宝公开详情 | 两个 `pcdetail.taobao.com` 商品页成功提取名称和图片。 |
| 淘宝／天猫普通详情 | 四个 `item.htm` 样本返回登录跳转，需在浏览器打开后采集可见商品图。 |
| 拼多多 | 实际 `/m_goods-detail?goods_id=…` 完整链接提取到八张商品图。保留原分享网址及参数。 |
| 得物 | 实际 `dw4.co` 商品分享短链跳转到官方 `fast.dewu.com/page/productDetail` 后，成功提取 Polo 衫标题和三张不同的商品图。桌面二维码页及部分旧版跳转页仍不提供商品图。 |
| 唯品会 | 样本返回需要脚本填充的商品模板，需在浏览器加载商品图后采集。 |

带网址的分享文字可直接粘贴；短链接会跟随经过公网检查的跳转。有效淘宝、京东短链及拼多多域名别名尚无本轮真实成功样本，不能据此保证兼容。

得物可直接粘贴含口令、文字和网址的完整分享。仅有 App／小程序二维码的页面不能作为衣物导入；此时可在得物中保存商品图或截图，再上传至衣间。得物商品来源保留商品与款式编号，去除分享追踪参数。

## 网页采集工具

1. 展开“使用网页采集工具（Chrome / Edge）”，下载并解压。
2. 打开浏览器扩展管理页，启用开发者模式，加载解压后的 `yijian-browser-capture` 文件夹。
3. 在浏览器打开商品页面。需要登录时由你自行登录，将要导入的衣物图滚动到可见区域。
4. 点击衣间扩展，采集当前可见商品图，核对并选择一张，再点击复制。
5. 返回衣间“从链接导入”，粘贴并解析，确认预览后导入。去背景与 AI 识别和相册上传使用相同流程。

扩展仅在主动使用时访问当前标签页，截取可见区域并裁切所选图片。它不读取 Cookie、密码或其他标签页。复制内容包含所选图片、页面标题和保留商品编号参数的来源网址；请先检查预览是否带有遮挡或个人信息。当前支持可见的普通商品图片，不提取未加载图片、视频或跨框架内容。安装和权限说明见 [扩展说明](../integrations/browser-capture/README.md)。

采集图片在本机预览，导入时可选择去背景及 AI 识别；开启识别后，图片会交给你所选择的模型服务。未安装扩展时，也可保存商品截图后使用相册上传。

直接解析只访问公开网页及图片，不使用电商账号、浏览器 Cookie 或登录信息。候选图片通过本机预览，确认后才保存到衣柜。预览缓存有容量和时限限制，重启服务后需要重新解析。

网络请求逐跳检查公网地址并固定连接目标，限制响应大小和时间。代理软件返回 `198.18.0.0/15` 虚拟地址时，使用固定的 Cloudflare HTTPS DNS 查询实际地址，并继续执行公网检查；本机与私网地址不能用于商品导入。DNS 查询仅包含域名，协议说明见 [Cloudflare DNS 文档](https://developers.cloudflare.com/1.1.1.1/encryption/dns-over-https/make-api-requests/dns-json/)。
