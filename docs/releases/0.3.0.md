# 衣间 0.3.0 · Windows 桌面预览版

衣间是本地优先、免费开源的个人衣橱应用。Windows 安装版内置运行环境和去背景模型，双击打开独立窗口，无需安装 Python、Node.js 或注册账号。

- 整理服装与配饰，从照片、商品链接或手动录入开始。
- 自由拖动、旋转和缩放衣物，按类别或拼图创建穿搭。
- 使用日历、穿着记录、洗护、旅行打包、统计和完整备份。
- 自行接入模型 API、已有本地模型或 Codex／Claude Code。AI 能力和额度由所选服务提供。
- 照片与记录保存在 `%LOCALAPPDATA%\Yijian\data`，应用升级与卸载保留数据。

下载 `Yijian-0.3.0-windows-x64-Setup.exe` 安装；ZIP 包供手动解压使用。`SHA256SUMS.txt` 提供两个文件的校验值。

支持目标为 Windows 10 22H2／Windows 11 x64，已在 Windows 11 实机验证。缺少 Microsoft WebView2 时，安装程序会联网准备窗口组件。安装程序尚未代码签名，Windows 可能显示未知发布者提示。

源码版用户可先导出衣柜 ZIP，再在安装版的空衣柜中恢复；AI 密钥与助手授权需要重新配置。更新使用新安装包覆盖安装，建议事先导出备份。

验证通过：608 项 Python 测试、12 项子测试、212 项前端测试，以及实际窗口、去背景、备份恢复、安装、升级和卸载数据保留检查。详情见 [验证记录](../validation.md)。
