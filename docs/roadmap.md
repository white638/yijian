# 项目路线

衣间优先交付普通用户可安装的 Windows 本机应用。核心功能免费，应用源码采用 MIT 许可证，用户自行选择 AI 服务，照片和衣柜保存在自己的电脑上。

## 已有个人衣柜能力

- 衣物与配饰管理，照片录入、商品链接导入、自动去背景与信息确认。
- 自由画布、按类别选择、拼图、规则推荐和可选 AI 推荐；支持旋转、缩放和图层顺序。
- 穿搭日历、实际穿着与洗护记录、花费统计、旅行打包与 ZIP 备份。
- 自带密钥接入模型 API，已有本地视觉模型服务，以及 Codex / Claude Code 助手模式。
- 可选图片美化，先预览后采用，并保留规范化原图。

具体能力及边界以 [使用说明](desktop.md) 和对应功能文档为准。

## 当前重点：Windows 安装与日常使用

当前为 **v0.3.0 桌面预览版**，支持 Windows 10 22H2 / Windows 11 x64。[安装说明](desktop.md)包含下载、校验、数据位置与构建方式。

桌面预览版提供以下体验：

1. 安装包携带应用运行环境，普通用户无需自行安装 Python、Node.js 或前端依赖。
2. 点击打开应用；妥善处理端口占用、重复启动和退出时的后台进程。
3. 衣柜数据与程序安装文件分开，更新保留数据，卸载行为清楚可见。
4. 首次引导可配置或跳过 AI。图片资源准备有可见状态，失败后仍可用原图录入。
5. Windows 实机验收覆盖安装、覆盖更新、卸载、应用窗口与接口、本机去背景和备份恢复。更多硬件与系统组合继续通过预览版收集反馈。

后续优先完善安装兼容性、错误诊断和日常使用稳定性，再评估代码签名与更新体验。当前安装包未签名，采用手动下载安装更新。

官网用于产品介绍、文档和真实安装包下载。下载入口只指向已发布且可核验的文件。

## AI 由用户选择

衣间不提供平台免费 AI 额度。手动衣柜、穿搭工具、规则推荐、记录和统计可独立使用；自动去背景使用随应用准备的本机图片组件。

需要生成式 AI 时，用户可选择自己的 API、已有本地模型，或连接支持相应操作的助手。API 费用由服务商结算，本地模型使用自己的硬件，助手模式遵循宿主的工具和额度规则。保留确认与编辑流程，避免识别结果覆盖未保存的手动修改。

## 后续：手机录入与跨设备

桌面版稳定后，再评估手机拍照录入、设备配对和跨设备数据管理。当前本机服务绑定本机地址，衣柜备份可迁移到另一台电脑；移动应用、局域网配对和自动同步尚无发布日期。

后续方案需先解决设备授权、照片传输、冲突处理和数据恢复，再提供普通用户可用的入口。

## 高级自托管实验

仓库保留 `online/` 中的账号隔离、私密分享、数据迁移和 Node / Cloudflare Workers 适配代码，采用 MIT 许可证，供开发者研究或自行部署。认证、存储、资源费用和运维由部署者管理，具体状态见 [实验部署说明](online.md)。
