# 创建穿搭

从首页或穿搭页点击“创建穿搭”。四种方式共用当前选择，可切换后继续编辑，包袋和配饰都能加入，每套最多 24 件单品。

| 方式 | 操作 |
| --- | --- |
| 自由拖动 | 从衣柜挑选单品，拖动位置；选中后拖右下角手柄缩放、顶部手柄旋转，也可用滑条及图层按钮调整。 |
| 按类别 | 查看各类别的已选单品，使用衣柜分类和搜索挑选。搜索包含名称、品牌、类别和标签。 |
| 拼图 | 选择均衡、网格或杂志版式，自动排列后继续调整位置和背景。 |
| AI 推荐 | 设置气温和场合，获取推荐后点击“选用并编辑”，再调整衣物或布局。 |

在拼图模式中增删单品，会按当前模板重新排列。自由拖动模式保留已有单品的位置、大小、旋转和图层；切换方式及重新打开已保存搭配不会重新排列。

画布手柄支持鼠标和触摸。键盘聚焦单品后，方向键调整位置；聚焦缩放或旋转手柄后，方向键微调大小或角度，Shift 加快。滑条保留，方便精确调整。缩放以单品中心为基准，大小范围为画布宽度的 8%–85%。

模型接口或 Ollama 配置了可用的文本模型时，推荐入口使用所配置的服务。Codex 与 Claude Code 通过对应宿主会话生成搭配；网页提供规则推荐。结果显示“AI 推荐”或“规则推荐”；选用后仅调整版式会保留推荐来源，增删单品后以手动搭配保存。

“保留已选单品再推荐”最多保留 12 件。超过上限时页面会提示并停止生成，可减少所选单品或取消保留后重新推荐。手动搭配仍可完整保存最多 24 件。

手动搭配可以保存局部组合。自动推荐需要上衣、下装、鞋，或连衣裙与鞋；适合的外套、包和配饰可进一步加入。规则推荐主动考虑最多一个包与两件不同种类的配饰，并保留基础方案。季节、场合和温度用于筛选自动加入的配饰，锁定、排除、可用状态和不搭组合继续生效。

包袋归入“包袋”；帽子、围巾、腰带、手表、项链、耳饰、戒指及其他首饰归入“配饰”，使用名称与标签区分具体种类。分类与季节信息越完整，推荐越容易选到合适单品。

## 保存与恢复

底部保存栏随编辑页面保持可见。点击“保存穿搭”会同时保存衣物编号、位置、大小、旋转、图层顺序、背景及创建方式。保存期间编辑区锁定；若保存失败，会恢复编辑并保留当前草稿。重新打开时还原布局，穿搭页预览也使用该布局。保存、安排日期都不会增加穿着次数；实际穿过后使用“这天穿过了”。

布局以固定 4:5 画布上的相对坐标保存，手机与桌面共享同一份数据。布局作为搭配记录的一部分进入完整备份。旧版无布局搭配打开后自动排列，可继续编辑；删除衣物后会同步清理其布局位置，其他单品和历史记录保留。

手机端依次呈现创建方式、画布和衣柜；桌面端将画布与衣柜并排。未保存的编辑在当前编辑器中保留，关闭编辑器前请完成保存。
