# 界面验收

结果：通过。版本：0.2.0。日期：2026-09-09。

## 参考与适配

参考为用户提供的六张 Acloset 手机界面，涵盖首页、推荐偏好、穿搭、探索、衣柜和添加入口。验收将参考图与运行中页面截图对照，检查信息层级、导航、衣物排列与主要操作。商业产品截图和其中的个人资料不随源码分发。

| 页面 | 实现与检查结果 |
| --- | --- |
| 首页 | 保留推荐、快捷入口、最近衣物和日历的顺序。手机单列，电脑将推荐与快捷入口、最近衣物并排排列。 |
| 衣柜 | 手机三列衣物网格，类别横向选择，搜索、排序和筛选独立；空图片有明确占位。 |
| 添加 | 相册、拍照、手动记录与自动去背景开关；新增衣物可逐件确认。 |
| 穿搭 | 穿搭、打包、日历三个标签；保存组合后可安排日期。 |
| 探索 | 选中真实衣物后围绕它生成组合，并清楚区分规则推荐与模型连接。 |
| 推荐偏好 | 城市、参考气温、温度敏感度、备注、排除单品、不搭组合与衣橱范围。 |

电脑端使用固定侧栏、宽屏网格和并排日历面板；手机端使用底部导航与中央添加按钮。

## 实际操作

- 浏览器视口：390 × 844、1440 × 1000；首页、衣柜与桌面日历截图已人工检查。
- 首页和衣柜没有页面级横向溢出；类别及推荐列表允许局部横向滚动。
- 首次使用显示 AI 选择，首屏可直接跳过；启动链接中的授权片段在页面读取后清除。
- 打开衣物详情时焦点进入弹窗；Escape 关闭后返回触发衣物卡片。
- 手动创建、上传并确认照片、保存推荐、记录及撤销穿着均完成实际操作。
- 通过日期输入框原生键盘修改日期并保存，日历正确区分次日计划与当日实际穿着。
- 创建旅行、从整套搭配加入三件衣物并勾选打包已完成实际操作。
- 选定衣物后生成推荐，锁定状态和结果可见。
- 说明文字、表单提示、占位提示和非当前导航采用次要色 `#6b6b78`，对白底对比度 5.25:1，对 `#f4f4f8` 浅灰底为 4.79:1；已从实际导航核对计算后的文字颜色，黑底添加按钮仍为白字。
- 本轮页面控制台未观察到错误日志。

验收使用隔离的测试衣橱；用户默认数据目录不包含这些验收单品。手机为浏览器响应式视口检查，不代表已验证真实手机硬件。
