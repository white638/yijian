# 图片美化

图片美化把衣物或配饰照片转换成整洁的单品展示图，目标是保留物品的颜色、图案、结构和材质，整理背景、摆放与光线。使用前需要启用并连接图像服务。

## 配置

在「设置 → 图片美化」选择一种方式。图片美化的设置独立于衣物识别，默认关闭。

| 方式 | 准备与执行 |
| --- | --- |
| 图像 API | 填写自己的密钥，选择 GPT Image 2、GPT Image 2.5 Flare 或 GPT Image 2.5 Sunburst。默认地址为 OpenAI；兼容服务需支持图片编辑，并填写其实际模型名称。网页直接提交生成请求。 |
| Codex | 先在 AI 设置中连接 Codex 并更新衣间 Skill。网页创建任务后，将页面提供的请求发给已连接的 Codex，由它使用当前会话的内置图片生成工具处理。 |

API 使用的模型标识为 `gpt-image-2`、`gpt-image-2.5-flare`、`gpt-image-2.5-sunburst`。具体权限和费用由用户的服务账户决定。[OpenAI 模型文档](https://developers.openai.com/api/docs/models/gpt-image-2.5-sunburst)

Codex 生图消耗 Codex 额度，使用宿主提供的图像模型；连接授权不代表助手会在后台自动接收任务。当前需要将 AI 助手模式设为 Codex 并保持授权有效。[Codex 图片生成说明](https://developers.openai.com/codex/image-generation)

密钥只在衣间服务端加密保存，不会返回网页或进入衣橱备份。保存配置不会触发生成。识别衣物使用的 API 或本地模型配置不能直接替代图像编辑服务。

## 使用

1. 打开一件带照片的物品，选择「图片美化」。
2. 检查所选服务，点击生成。API 模式在网页等待；Codex 模式复制处理请求到已连接的助手。
3. 对比原图与美化图，核对颜色、版型、印花、文字和配饰细节。
4. 满意后选择「采用美化图」。也可以继续保留当前图片，或恢复原图。

生成不会自动覆盖衣柜里的图片，也不会修改衣物属性。恢复原图无需再次生成，已完成的美化图仍可再次采用。每次重新生成都会产生一次新的服务调用。

## 数据与任务

原图、美化图分别保存；衣橱备份包含两者。这里的原图是上传后按方向和尺寸规范化的 JPEG，美化结果也按同样的图片规范保存，并清除元数据。

任务可取消。取消后迟到的结果不会被采用，但已发出的 API 请求可能仍由提供商计费。请求超时不会自动重试；先检查账户再决定是否重新生成。

Codex 任务由已验证的同一助手领取和回传，处理期最长 15 分钟，且不能超过当前授权有效期。取消、原图变更或授权失效后，过期结果会被拒绝。服务重启会结束执行中的任务，需要用户重新发起。

美化生成可能改变细节，因此结果保留在预览中等待核对。多件同框、遮挡和精细首饰尤其需要检查；一次任务只处理所选物品。
