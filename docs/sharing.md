# 衣柜分享

状态：第二阶段功能规格，尚未在当前本机版提供。

## 使用流程

从衣柜中的“分享衣柜”进入，选择需要建议的衣物，填写问题，例如“这两件周末一起穿合适吗？”。创建前展示访问预览，确认衣物和图片，以及链接有效期。默认有效期为七天，可选一天或三十天。

创建后进入“我的分享”详情：问题、所选衣物、有效期、分享按钮和收到的建议。用户可以复制链接，或调用设备原生分享菜单。链接持有人可以访问，也可以继续转发；创建页明确说明这一点。

朋友打开链接后直接看到问题和衣物，按类别筛选，点击“给出建议”。可以只写文字，也可以选择其中几件衣物组成搭配。昵称可选，提交成功后显示确认；每位访客只看到本次提交的确认内容。

主人查看全部建议，选中喜欢的组合后点击“保存为搭配”，核对名称和衣物再保存。保存前重新检查单品的所有权、存在性、确认状态和可用状态；失效单品明确标出，等待主人调整。

移动端以问题、衣物网格、底部建议入口依次呈现。桌面端将问题和建议表单放在侧栏，衣物网格使用主内容区域；两端共享功能和状态。

## 内容与访问

分享只包含问题、选定衣物的展示名称、类别、品牌及独立照片快照。创建预览允许主人核对这些字段。照片清除元数据；服务端按字段白名单输出，购买价格、参考价格、私人备注、位置、账号和 AI 配置保持私密。

快照固定分享时的内容，后续衣物编辑不会扩大分享范围。删除原衣物时，在确认页展示受影响的分享；确认删除后使相关分享失效并清理其照片快照。修改分享范围需重新生成链接。

分享凭证使用至少 128 位安全随机值，服务端只存哈希。凭证放在链接片段中，由页面提交给分享访问接口，避免进入普通页面请求和引用来源；服务端响应和访问日志不得记录凭证。分享页不加载第三方分析脚本，设置禁止搜索引擎收录和不发送引用来源；分享不进入公开目录、站内搜索及 sitemap。

分享图片存放在私有存储，由分享访问接口逐次检查权限后返回。响应使用私有、不缓存策略；撤销立即阻止后续服务端访问。访客已经下载或保存的内容不能远程收回。

访客只能查询这一分享的快照、提交建议。提交只接受本次分享的快照编号，服务端验证后映射原单品。主人的衣柜接口、其他人的建议和分享管理操作始终要求主人账号授权。

## 状态与管理

| 状态或操作 | 链接持有人可做的事 |
| --- | --- |
| 接受建议 | 查看本次衣物并提交建议。 |
| 关闭回复 | 查看本次衣物；服务端拒绝新回复。 |
| 到期或撤销 | 页面显示链接已失效，图片及回复接口拒绝访问。 |
| 重新生成 | 新链接生效，旧凭证立即失效；主人保留已收到的建议。 |

主人可以删除建议、关闭回复、撤销链接和重新生成。关闭与提交以原子条件更新协调；在关闭完成后提交的请求必须被拒绝。创建分享、提交回复、加载图片分别设定额度，使用分享编号与短期来源标识限流。文本长度受限，重复请求去重；异常流量可触发验证。

## 双版本与迁移

云端版和自托管版提供相同分享流程。朋友需要能够访问部署实例的网址；自托管实例应配置可访问的 HTTPS 地址。

迁移包可包含主人的分享历史、所选衣物关系和收到的建议，回复页说明建议会交给主人保存。有效分享凭证、会话和防滥用来源标识不进入迁移包。

迁入目标实例后，历史作为只读记录保存。再次分享生成目标实例的新链接。原站链接继续遵循原站的有效期和撤销状态，迁移预览提示用户可到原站关闭仍有效的分享。两端分别管理分享权限，个人衣柜同步不会自动创建分享。

## 验收

1. 主人选择衣物与问题，朋友通过链接免注册回复，主人将有效建议保存为搭配。
2. 访客接口不得自动输出价格、私密备注、账号标识及未选衣物等衣柜私密字段；自由文字和照片以主人预览确认的内容为准。枚举其他分享或单品编号不能扩大访问范围。
3. 关闭回复后并发提交被拒绝；过期、撤销及重新生成后旧链接的页面、照片和回复访问一并失效。
4. 删除衣物后相关分享失效；历史建议中缺失的衣物明确显示，保存搭配时要求调整。
5. 迁移保留所选衣物关系和建议，不复制有效凭证；新旧实例的链接及权限独立管理。
6. 在移动端、桌面端和键盘操作下验证选择、预览、取消、错误恢复、提交和管理流程。
