## 功能检查

在独立的测试衣橱中完成照片上传、真实 CPU 去背景、恢复处理前图片、手动属性确认、规则搭配、保存搭配、安排日期、记录与撤销实际穿着、整套加入旅行清单和勾选打包。

使用真实 HTTP 服务和独立助手命令行完成 27 项集成检查，覆盖一次性连接码、权限边界、衣物读取、图片下载、标签回写、组合校验及断开授权。图片检查使用 u2netp 与自行构造的衣物图形，处理图确实改变，恢复图与规范化原图逐字节相同。

助手连接完成 Windows 本机实测：网页安装个人技能、核对并批准短码、DPAPI 保存授权、独立命令重新读取凭据和衣柜。服务重启及技能更新后连接仍可用，安装文件摘要与源文件一致。配对测试覆盖批准、拒绝、一次性兑换、过期、限频、请求编号关联和当前授权撤销；CLI 测试覆盖失败回滚、并发文件锁及重连后旧授权清理。技能升级备份保存在技能搜索目录外。

模型接口测试使用可控的模拟响应，覆盖地址校验、超时、输出验证、配置切换和任务取消。未使用真实付费云模型评估搭配或识别质量，也未将模拟结果视为宿主模型推理验收。

## 界面检查

以 390 × 844 与 1440 × 1000 的浏览器视口检查手机和电脑布局。核对底部导航、桌面侧栏、衣柜网格、中文动态洞察、弹窗 Escape 关闭与焦点返回、日历及打包流程。具体结果见 [界面验收](design-qa.md)。

助手连接页在这两个视口均无横向溢出；实际配对完成后显示 Codex、验证时间和授权到期时间。浏览器检查未发现连接页控制台错误或警告。

## 适用范围

当前为单用户本机应用。Claude Code 的接口与安装路径通过自动测试，未进行真实 Claude Code 会话验证。真实手机硬件、Safari、跨设备部署和公网多用户服务未在本轮验证。去背景质量依赖照片内容，复杂背景及细节应人工检查。
