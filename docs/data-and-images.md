# 数据与图片

## 数据目录

默认 `.local/data`，可通过启动参数 `--data` 指定其他目录。目录包含 `wardrobe.sqlite3`、图片、图片处理资源及本机 AI 密钥文件。数据文件不会进入源码仓库。

备份导出衣物、原图与处理图、搭配、日期计划、穿着和洗护事件、旅行清单及普通偏好。API 密钥、加密密钥文件、浏览器会话和助手授权均不进入备份。

恢复需要空衣橱，先校验格式、图片摘要、路径和衣物引用，再写入。导出与恢复使用相同容量上限：96 MiB 压缩文件、256 MiB 展开内容、单文件 24 MiB、清单 8 MiB、10,000 个 ZIP 条目和 2,000 件衣物。超过容量时导出会明确提示，避免生成无法恢复的备份。请将重要备份另存到独立设备。

## 衣物备份导入

支持 `wardrobe-commons-backup` v1 ZIP。导入保留衣物编号、名称、购买信息、照片、穿着与洗护记录。没有币种的历史金额保持未知；较细的衣物类型映射到新的类别，完整原属性保存在导入元数据中。

原备份中的穿着总次数可能多于逐次记录。差额保存为历史穿着次数，不虚构日期事件。旧备份格式本身不包含的搭配、计划和旅行清单无法从该 ZIP 恢复；完整工作区备份包含这些内容。

## 自动去背景

安装程序自动准备图片依赖和约 4.6 MB 的前景提取资源。用户不需要选择或启动模型服务。首次安装需要网络；资源就绪后，在本机处理图片，上传请求不会触发资源下载。

支持 JPEG、PNG、WebP，单张上传最多 16 MiB、2,500 万像素，每批最多 20 张。图片按方向信息校正，最长边缩至 2,400 像素，并规范化为 JPEG。这里的“原图”指规范化后、去背景前的照片；不会保留相机原文件及其全部元数据。

去背景生成白底 JPEG，保留独立原图。恢复时引用原图，不用再次压缩。复杂背景、镂空、半透明材质和同色衣物可能需要人工检查；失败时衣物保留原图并提示。

不需要去背景时，可在添加衣物时关闭；之后可在详情中重新处理。当前版本不提供多件同框自动拆分、透明 PNG 导出或虚拟试衣。

## AI 配置

接口模式需要用户提供服务地址、模型名称及适用的密钥；已有 Ollama 服务也属于需要准备的 AI 环境。应用不会把手动推荐或图片去背景描述成已连接大模型。

Codex / Claude Code 模式的推理由宿主会话执行。插件只获得你授权的衣橱访问能力，不读取宿主登录文件、API 密钥或浏览器凭据。它不能把订阅额度变成网页中的无限自动推理。
