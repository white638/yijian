# 衣间 · Yijian

用自己的衣服，搭配今天。

衣间是免费开源的个人衣橱应用，独立实现衣物管理、穿搭规划和 AI 助手接入。手机上随手录入，电脑上整理、组合与规划。照片和衣橱保存在自己的电脑，采用 MIT 许可证。

## 日常使用

- **首页**：今日推荐、常用操作、最近添加和穿搭日历。
- **衣柜**：照片录入、自动去背景、属性确认、分类筛选、待洗与归档。
- **添加**：相册、拍照或手动录入；图片识别后由你确认衣物信息。
- **穿搭**：挑选自己的单品保存搭配，安排穿搭日期，建立旅行打包清单。
- **探索**：选定一件衣物，探索自己衣橱中的不同组合。

首次使用可以连接模型接口、选择 Codex / Claude Code，或暂时跳过。衣物管理、手动搭配、规则推荐、日历、花费统计和备份可以独立使用。

手机使用底部导航；桌面使用侧边导航和更宽的内容布局。中文界面包含动态洞察、错误提示和表单说明。

功能入口采用原创彩色立体图标，页面、弹层和保存操作提供轻量动态反馈，并支持系统的减少动态效果偏好。[查看可编辑设计稿](https://www.figma.com/design/mSstCkkKPJaEyxA0ToLGTz)。

## 启动

需要 Python 3.11+ 和 Node.js。首次安装会下载依赖与图片处理资源，后续运行复用本地缓存。

```bash
git clone https://github.com/white638/yijian.git
cd yijian
python scripts/start.py
```

启动程序自动建立本地环境、构建网页、准备图片组件，并打开本机入口。浏览器未自动打开时，使用终端输出的本机入口链接。默认数据目录为 `.local/data`，包含 SQLite 数据库、照片和个人设置。关闭运行终端即可停止服务。

```bash
python scripts/start.py --data /path/to/my-wardrobe --port 3110
```

应用面向一台电脑上的个人使用，服务绑定本机地址。手机布局可在浏览器设备预览中使用；跨设备访问需要额外的认证和部署方案，当前启动方式不提供公网或局域网登录。

## AI 与图片

在首次引导或设置中选择：

| 方式 | 使用场景 |
| --- | --- |
| 模型接口 | 网页中识别衣物、生成搭配、与造型助手对话；可配置 OpenAI、兼容接口或已有 Ollama 服务。 |
| Codex / Claude Code | 在宿主会话中使用衣间 Skill / 插件，读取自己的衣物并写回标签与搭配。 |
| 暂时跳过 | 手动整理衣橱、使用规则搭配和规划工具。 |

模型接口的密钥仅在服务端加密保存。保存配置不会发起推理；连接测试需要点击测试按钮。云端费用由所选服务商结算。

宿主模式使用当前 Codex / Claude Code 会话可用的模型、工具和额度，额度按宿主规则计算。在 AI 设置中安装技能，把连接请求发给助手，再在网页核对短码确认。只有助手安全保存授权并实际读取衣柜后才显示已连接。配对请求五分钟有效，授权一小时，可在设置中立即断开。详细步骤见 [助手模式](docs/assistant-mode.md)。

自动去背景使用随应用准备的图片组件，无需为它填写密钥、挑选模型或启动模型服务。组件在电脑上处理照片；请求期间不下载模型。支持 JPEG、PNG、WebP。上传后保留规范化原图和处理图，去背景失败时保留原图；可以恢复处理前图片。细节见 [数据与图片](docs/data-and-images.md)。

## 数据与记录

保存搭配、安排日期和标记已打包都不会增加穿着次数。只有“记录穿过”生成实际穿着事件；支持撤销。

购买价格按币种分别统计。零元与未填写价格分别处理；未穿过的衣物不计算单次穿着成本。待洗、归档和未确认衣物不会进入推荐。锁定、排除和不搭组合会约束规则与 AI 推荐，返回的单品必须真实存在。

设置中可以导出完整衣橱备份，包含衣物、照片、搭配、计划、穿着与洗护记录、旅行清单和普通偏好；模型密钥与助手授权不进入备份。恢复要求空衣橱，并验证图片、引用和文件路径。也支持导入 `wardrobe-commons-backup` v1 衣物备份。见 [数据说明](docs/data-and-images.md)。

## 开发

Python / FastAPI / SQLite，React / TypeScript / Vite。开发不需要额外数据库和任务队列服务。

```bash
python -m pip install -r requirements-dev.txt
python -m pytest
cd web
npm ci
npm test
npm run build
```

API 与组件边界见 [架构](docs/architecture.md)，实际检查结果见 [验证记录](docs/validation.md)。

## 设计与许可

界面信息结构参考 Acloset 的首页、衣柜、穿搭和探索流程，衣物成本与旅行规划也参考了相关衣橱产品的使用体验。应用源码、数据结构和交互由衣间独立实现，商业产品的品牌、商品图和社区内容不随项目发布。
